# Sippy Cart Sharing

Sippy Cart Sharing is a Flutter app that allows users to create sessions and share shopping carts with others in real-time. Users can add products to a shared cart, view and update product quantities, and complete the checkout process. The app supports session-based cart sharing with different user roles (creator and guests).

## Features

- Real-time cart sharing between users in a session
- Ability to add products to the cart
- View product details, prices, and quantities
- Shopping cart summary and checkout
- Support for guest and creator roles in the session
- Session management (create and join sessions)

## Prerequisites

Before running the project, ensure you have the following installed on your system:

- Flutter 2.0 or above: [Install Flutter](https://flutter.dev/docs/get-started/install)
- Dart SDK: Included with Flutter installation
- Android Studio or Visual Studio Code (with Flutter plugin) for development
- A device/emulator for testing

## Installation

Follow the steps below to set up the project on your local machine:

1. **Clone the repository:**
   git clone https://github.com/nicholasovunda/sippy-sync-cart.git

2. **Navigate into the project directory:**
   cd sippy_cart_sharing

3. **Install dependencies:**
   flutter pub get

4. **Run the app:**
   flutter run
